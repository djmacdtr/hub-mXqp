# LLM Smart Cache 架构设计

## 1. 总体结构

```text
用户输入
  -> 本地 embedding 方法
  -> FAISS 向量检索
  -> Redis 数据存储
  -> 缓存命中 / 历史召回 / 语义路由
```

## 2. 模块职责

- Redis：保存缓存值、消息历史、路由定义、TTL。
- FAISS：保存向量索引，并进行最近邻检索。
- 本地 embedding：将文本转换成固定维度向量，用于教学演示和单元测试。
- 4 个组件：对外提供类似 RedisVL 的简化接口。

## 3. 数据流

### Embedding 缓存

```text
文本 -> md5 key -> Redis hash 保存向量 bytes/dtype/dim -> 下次直接读取
```

### 语义缓存

```text
prompt -> embedding -> FAISS 检索相似 prompt -> Redis 读取 response -> 返回命中结果
```

### 对话历史

```text
session_id -> Redis list 保存消息 -> 最近消息 / role 过滤 / 语义相关召回
```

### 语义路由

```text
route references -> embedding -> FAISS 索引
用户问题 -> embedding -> 找最相似 route -> 返回 target
```

## 4. 设计取舍

本作业没有直接使用 Redis Stack 的向量索引，而是使用 Redis + FAISS 组合。这样可以在本地 Docker Redis 上更容易跑通，适合课程作业演示。

生产环境中可以进一步替换为 RedisVL + Redis Stack，通过 RediSearch 管理向量索引、过滤条件和混合检索。
